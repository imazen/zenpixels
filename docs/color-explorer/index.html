Cross-platform reality

Working-space white, display white and HDR peak are different values. Windows scRGB's nominal 1.0 is 80 nits; the CSS HDR draft uses 203 nits for SDR reference-white anchoring. Neither is a universal image default. Apple's EDR pipeline introduces its own display/headroom context.

PNG defines color-chunk precedence; carrying two blocks does not mean both are equally authoritative. Destination encoders must follow their format's rules. This model marks platform support unknown rather than guessing from a file extension.
