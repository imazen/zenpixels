## Notes

- Resampling interpolates encoded `[0, 1]` gain samples using `zenresize` center-sited separable weights (`(out + 0.5) / scale - 0.5`, unit-sum normalized in `f64`), caching horizontally-upsampled gain rows so each ¼-res gain-map row is decoded and horizontally filtered once per frame.
- `Bicubic` (Catmull-Rom 4-tap) adds only `1.5 ms` (+8.7%) over `Bilinear` (2-tap) at full 4K UHD.
- Unlocking `FastRow::F32ToF16` when only one side leaves `DiffuseWhite` unspecified (`white: Some(BT2408)` → `None`) reduced `apply_qres_bilinear_u8_to_rgbaf16` from `36.4 ms` to `23.7 ms` (-35%).
